# AI Movie Recommendation System

##  Overview
The AI Movie Recommendation System is a simple content-based recommendation system developed using Python. It recommends movies to users based on the movie they enter. The system analyzes movie genres and descriptions using Natural Language Processing (NLP) techniques and suggests similar movies.

This project was developed as part of the **CodeSoft Artificial Intelligence Internship**.

## Features

-  Recommend movies based on user preferences
-  Uses Content-Based Filtering
-  Uses TF-IDF Vectorization for feature extraction
-  Uses Cosine Similarity to find similar movies
-  Attractive Tkinter GUI
-  Handles invalid movie names gracefully
-  Clear and Exit buttons for better user experience

## Technologies Used

## ▶️ How to Run

1. Clone the repository.
2. Open the project in VS Code.
3. Install the required libraries:
pip install -r requirements.txt

4. Run the application:
python main.py

5. Enter a movie name and click **Recommend** to get similar movie suggestions.

##  Output
The application provides:
- User-friendly GUI
- Movie input field
- Recommend, Clear, and Exit buttons
- Top 5 recommended movies based on similarity
