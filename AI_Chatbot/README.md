#  AI Rule-Based Chatbot

A simple and interactive **Rule-Based AI Chatbot** developed using **Python** and **Tkinter**. The chatbot responds to user queries using predefined rules and pattern matching, making it a great beginner-friendly Artificial Intelligence project.

## Features

-  Greets the user
-  Responds to "How are you?"
-  Introduces itself
-  Tells who created it
-  Shows the current time
-  Shows today's date
-  Responds to "Thank You"
-  Says goodbye
-  Handles unknown questions gracefully
-  User-friendly graphical interface using Tkinter

## Technologies Used

- Python
- Tkinter
- Regular Expressions (re)
- Random Module
- Datetime Module

```bash

```

2. Navigate to the project folder:

```bash

```

3. Run the application:

```bash

```
